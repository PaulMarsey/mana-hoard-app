# Drop TCG PowerTools exports here

Upload your PowerTools stock export (CSV) to this folder on GitHub (**Add file → Upload files**). The next deploy merges it into `data/stock.json` and deletes the file. You can also start a deploy straight away from **Actions → Sync stock and deploy → Run workflow**.

⚠️ This repository is public. A file uploaded here stays in the repo's history even after it's deleted. If your export includes purchase prices (`buyPrice`) or notes you'd rather keep private, delete those columns before uploading, or use the **TCG PowerTools** tab in the Hoard Manager instead (the file never leaves your browser).
